# 🐜 Age of Anthills

A single-player ants RTS that runs entirely in your browser — no install, no sign-up.
Found a colony, dig your anthill, send workers to forage, raise soldiers, and outlast rival
colonies (and the wildlife) across day, night and the seasons.

**Controls** — mouse: right/middle-drag or WASD to pan, wheel to zoom, left-click the minimap to jump.
Touch: one finger pans, pinch to zoom. There's an in-game **field guide** (the book icon).

This repository holds only the static build (client, the compiled `motor.wasm` engine and the guides) —
the same files your browser downloads to play. The engine source (Rust), the multiplayer server and the
design docs are not here. Multiplayer is off in this build; it's the against-the-machine game.
